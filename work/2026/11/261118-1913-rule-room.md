## Intent

The person asked to do first a small item on the kit, before a first project adopts it: regain room in the checker
and the worker by removing text, and correct the README's sentence that calls the kit public while its repository
is private. Asked on 2026-11-18, accepting a proposal to do this item first.

## Acceptance criteria

1. `agents/checker.md` and `agents/worker.md` are each at least 300 characters shorter, and lose no check and no step:
   only words, and sentences that another part of the same file or the core rules already state.
2. The README no longer states that the kit is public; it says that whatever is committed counts as public, whatever
   the repository's visibility.
3. The kit's `verify` list passes.

## Strategy

Shorten sentences in place; delete a sentence only where the same file says it again or, in the worker, where the
core rules, which the worker receives, already state it. The checker receives no core rules, so what it must check
stays written out there. The budgets in `checks/budgets.test.mjs` stay as they are: the room gained is the margin.

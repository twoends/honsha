## Intent

The person asked to record three lessons, each at its level, as short preventive rules with no history, as the
core rules' section Lessons says; to add `lessons` to the kit's profile, and the kit's lessons file with its project
lesson; and to say in the record how lessons reach a session today: section 8 says a session receives them, but
nothing loads them yet (the hub will, from phase 2). The loading was to be built only if it is trivial and has one
reasonable design; otherwise it was to be noted in the record as an open point. Asked on 2026-11-18, from the home's
report `261118-1348`.

## Strategy

A root file `LESSONS.md`, named by a new `lessons` key in `.hub/profile.yml`: one existing file, within the six of
`upkeep`. Of the three lessons, the one about `git add -A` concerns this repository's working tree and goes there; the
shell's expansion of double-quoted text is a property of the machine's shell, so a host lesson; inline scripts given
to `node -e` concern every project that uses Node.js, so a technology lesson. The last two go to the home. Loading is
judged against its designs before anything is built.
